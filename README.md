# 🖨️ 3D Mohr Circle & Failure Evaluator

3차원 응력 상태와 모어 원(Mohr Circle)을 이용한 3D 프린팅 재료 파손 평가 프로그램

---
## 📌 프로젝트 이름

### **Mohr 원을 이용한 3D 프린팅 재료 파손 평가 프로그램**

---

## 📝 한 문장 설명

사용자가 입력한 3차원 응력 상태와 3D 프린팅 재료 정보를 바탕으로 주응력을 계산하고, 모어 원 시각화 및 파손(Failure) 가능성을 평가하는 고체역학 기반 Python 프로그램입니다.

---
## 🎯 제작 동기

최근 3D 프린팅 기술을 활용하여 다양한 부품과 제품을 제작하고 있습니다.

하지만 이렇게 제작된 제품이 실제 하중 조건에서 제 기능을 수행하지 못하고 쉽게 파손(Failure)된다면 설계의 의미가 퇴색됩니다.
따라서 주어진 응력 조건하에서 제품이 안전하게 기능하는지 평가하는 수학적/역학적 수단이 필요합니다.
본 프로젝트를 통해 3차원 응력 상태에서 주응력을 계산하고, 선택한 재료의 특성 및 안전계수를 기반으로 제품의 파손 위험을 직관적으로 평가하는 프로그램을 구현하고자 합니다.

---

## ⚙️ 핵심 기능 3가지


### 1️⃣ 3차원 응력 상태 입력 및 주응력 계산

- 사용자로부터 3차원 응력 텐서의 6개 독립 성분(σx, σy, σz, τxy, τyz, τzx)을 입력받습니다.
- 입력된 값을 기반으로 3x3 응력 텐서를 구성하고, 행렬의 고윳값(Eigenvalue) 계산을 통해 주응력(σ1, σ2, σ3)과 본미세스 응력을 도출합니다.

### 2️⃣ 재료 데이터베이스 기반 파손(Failure) 평가

- 사용자가 3D 프린팅 재료(PLA, ABS)와 안전계수를 입력하면, 프로그램 내부에 구축된 재료 딕셔너리(DB)에서 해당 재료의 물성치(인장강도 등)를 불러옵니다.
- 재료의 성질(취성/연성)에 따라 적합한 파손 이론(최대 주응력 이론, 본 미세스 이론 등)을 적용하여 허용 응력을 계산하고, 현재의 응력 상태가 안전(Safe)한지 파손(Failure) 위험이 있는지 판정합니다.

### 3️⃣ 3D 모어 원(Mohr Circle) 시각화

- 계산된 세 개의 주응력을 이용하여 3차원 응력 상태에 대한 모어 원을 화면에 시각화합니다.
- 그래프 위에 세 개의 모어 원, 주응력 좌표, 기준축 등을 명확히 표시하여 사용자가 복잡한 응력 상태를 기하학적으로 쉽게 이해할 수 있도록 돕습니다.

CLI (Command Line Interface) 기반 Python 프로그램 (결과 도출 시 Matplotlib 팝업 창을 통한 시각화 제공)

## 🐍 사용할 Python 개념

- 변수: 응력 성분, 재료명, UTS, 안전계수 저장
- 조건문: Safe / Failure 판정
- 반복문: 사용자 입력 처리 및 재료 목록 출력
- 함수: 응력 계산, 재료 선택, 파손 판정, 그래프 출력 기능 분리
- 리스트와 딕셔너리: 재료 데이터 저장
- 예외 처리: 숫자가 아닌 값 입력 시 오류 처리
- 외부 라이브러리:
  - `numpy`: 응력 텐서 생성 및 주응력 계산
  - `matplotlib`: Mohr Circle 시각화

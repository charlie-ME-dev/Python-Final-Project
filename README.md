# Python Final Project 


**Mohr 원을 이용한 3D 프린팅 재료 파손 평가 프로그램**


- **Description** : 
3차원 응력 상태, 3D 프린팅 재료, 안전계수를 입력하면 주응력과 최대 전단응력을 계산하고, Mohr 원을 시각화한 뒤 허용응력과 비교하여 출력물의 파손 가능성을 평가하는 Python 프로그램이다.


## Problem Definition & Motivation

최근 3D 프린팅 기술을 활용하여 다양한 제품들을 만들고 있다. 하지만, 이렇게 만든 제품이 제 기능을 수행하지 못하고 쉽게 
파손된다면(failure) 좋은 제품이 될 수 없다. 따라서 주어진 조건하에서 제품이 정상적으로 기능하는지 평가하는 수단이 필요하다. 이에 응력조건이 주어졌을 때, 제품의 주응력을 계산하고 재료(필라멘트)의 특성과 안전계수를 기반으로 안전한지를 평가하는 프로그램을 만들고자 한다.


## 핵심 기능 3가지

### 1. 3차원 응력 상태 입력 및 주응력 계산

사용자로부터 3차원 응력 텐서의 6개 독립 성분인 `σx`, `σy`, `σz`, `τxy`, `τyz`, `τzx`를 입력받는다. 입력된 값을 이용해 3x3 응력 텐서를 구성하고, 고유값 계산을 통해 주응력 `σ1`, `σ2`, `σ3`와 최대 전단응력 `τmax`를 계산한다.

### 2. 재료와 안전계수를 이용한 Safe / Failure 평가

사용자가 3D 프린팅 재료와 안전계수를 입력하면, 프로그램 내부에 저장된 재료 데이터에서 해당 재료의 최대인장강도(UTS) 값을 불러온다. 이후 `허용응력 = UTS / 안전계수`를 계산하고, 최대 주응력 `σ1`과 허용응력을 비교하여 출력물이 안전한지 또는 파손 위험이 있는지를 판정한다.

### 3. 3D Mohr Circle 시각화

계산된 세 개의 주응력 `σ1`, `σ2`, `σ3`를 이용해 3차원 응력 상태에 대한 Mohr 원을 시각화한다. 그래프에는 세 개의 Mohr 원, 주응력 위치, 최대 전단응력이 표시되며, 사용자가 응력 상태를 숫자뿐 아니라 그림으로도 이해할 수 있도록 한다.


## 예상 사용자

- 3D 프린팅 출력물의 기초적인 강도 평가를 해보고 싶은 사용자
- 주어진 3차원 응력상태에서 Mohr 원과 주응력을 계산하고 싶은 사용자



## 결과물 형태

**CLI 프로그램**

사용자가 터미널에서 재료, 안전계수, 응력 성분을 입력하면 계산 결과가 출력되고, Mohr Circle 그래프가 표시되는 형태로 구현한다.



## 사용할 Python 개념

- 변수: 응력 성분, 재료명, UTS, 안전계수 저장
- 조건문: Safe / Failure 판정
- 반복문: 사용자 입력 처리 및 재료 목록 출력
- 함수: 응력 계산, 재료 선택, 파손 판정, 그래프 출력 기능 분리
- 리스트와 딕셔너리: 재료 데이터 저장
- 예외 처리: 숫자가 아닌 값 입력 시 오류 처리
- 외부 라이브러리:
  - `numpy`: 응력 텐서 생성 및 주응력 계산
  - `matplotlib`: Mohr Circle 시각화
